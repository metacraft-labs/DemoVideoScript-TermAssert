# DemoVideoScript-TermAssert

DemoVideoScript backend adapter that runs scenarios on terminal applications through TermAssert.

> **Status:** ☐ Planned — design stage; no implementation yet.

Implements the [DemoVideoScript](https://github.com/metacraft-labs/DemoVideoScript)
backend protocol in-process over the public API of
[TermAssert](https://github.com/metacraft-labs/TermAssert): a real pty and a `libvterm`
screen. Recordings are asciinema casts. Also carries the terminal binding of the
DemoVideoScript conformance application.
